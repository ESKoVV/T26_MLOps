# Реестр сторонних компонентов и лицензий

Перед tag выпуска команда формирует SBOM или отчёт зависимостей из фактически разрешённого окружения и проверяет имя, версию, источник и лицензию каждого распространяемого компонента. Нельзя угадывать лицензию по названию пакета.

Минимальная запись: компонент, точная версия, URL официального источника, SPDX-идентификатор из источника, способ использования/распространения, проверивший участник и дата. Неизвестная или несовместимая лицензия блокирует release до решения ответственного.

## Проверка 2026-10-28 (@ESKoVV, окружение из `requirements.lock`, Python 3.12.16)

Лицензии взяты из метаданных установленных пакетов (`License-Expression`/`License` и classifiers) и сверены
с официальными репозиториями по названию лицензии. Все компоненты используются как зависимости и не распространяются
в изменённом виде; runtime-образ содержит только зависимости из `[project.dependencies]`.
