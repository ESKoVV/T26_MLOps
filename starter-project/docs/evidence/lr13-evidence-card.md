# Evidence card ЛР13

| Поле | Что указать |
|---|---|
| Студент | ФИО, группа, команда, GitHub-логин |
| Командная версия | tag `lr13-v1`, commit SHA и contract version |
| Роль | зона ответственности и отличие от ЛР12 |
| Issue и PR | критерии приёмки и review другого участника |
| Личный артефакт | join, contract, test, audit, Feast definition или parity check |
| Индивидуальный запуск | входы, команда и путь к личному audit JSON |
| Evidence | naive leakage rows, PIT leakage rows, coverage и feature age |
| Решение | выбранная временная семантика, альтернатива и риск leakage |
| Использование ИИ | инструмент и самостоятельно проверенные утверждения |

Совпадающие карточки не принимаются. Скриншот Feast UI без исходных определений и
point-in-time теста не является индивидуальным артефактом.
