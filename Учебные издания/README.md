# Учебные издания курса MLOps 2026–2027

Дата сборки: 20 октября 2026 года.

## Учебное пособие

Каталог `Учебное пособие/` содержит редактируемый Markdown, DOCX и PDF. Издание объединяет
16 лекционных глав, навигатор демонстраций и демонстрационные/отказные сценарии лабораторных работ.
Материал предназначен для чтения, проведения занятий и подготовки к итоговому контролю.

## Лабораторный практикум

Каталог `Лабораторный практикум/` содержит редактируемый Markdown, DOCX и PDF. Издание объединяет
ЛР1–ЛР16, общий регламент командной работы по 2–5 человек, индивидуальную evidence card, правила
защиты и повторной сдачи, а также итоговый demo script и release/responsible-use checklists.

## Контроль версии

Издания собраны из актуальных Markdown-источников каталогов `Лекции/`, `Лабораторные работы/` и
проверенных документов `starter-project/docs/`. При изменении отдельной лекции или ЛР соответствующее
издание следует пересобрать и снова проверить постранично.
