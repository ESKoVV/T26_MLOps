## Найденные дефекты

1. **pyfunc отдавал метки классов.** Signature выводилась из вероятностей, но MLflow вызывал `predict()`, и
   `models:/…@champion` возвращал `[0]` на любой рейс. Теперь `pyfunc_predict_fn="predict_proba"`, signature на
   обе колонки, smoke в registry проверяет форму `(rows, 2)` и диапазон. Версии, зарегистрированные до исправления,
   удалены вместе с registered model, и сценарий выполнен заново.
2. **Promotion без независимого review.** `promote` принимал любой `--approved-by`. Теперь `register` пишет
   `registered_by`, а `promote` отказывает, если одобряет автор (без учёта регистра).

## Ограничение — нужен review участника

Обе promotion выполнены в учебном режиме `--drill` (одобрил сам автор): в manifest и tags это видно как
`review: self-drill`. Это отработка механики, а не выпуск. Настоящее promotion выполняет участник, который не
регистрировал кандидата:

```bash
python -m mlops_flight_delay.registry promote --tracking-uri http://127.0.0.1:5000 \
  --model-name team-3-flight-delay-classifier --data reports/prefect/lr10-run-a/prepared.csv \
  --approved-by <login-участника> --output reports/releases/lr10-release.json
```
