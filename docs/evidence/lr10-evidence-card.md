# ЛР10 — индивидуальная evidence card

- Студент, группа, команда, GitHub-логин:
- Tag командной версии: `lr10-v1`
- Роль в ЛР10 и отличие от ЛР9:
- Issue:
- PR или содержательный review:
- Личный артефакт:
- Model name / exact version / MLflow run ID:
- Source commit / data SHA256:
- Личный rejected, promotion или rollback-сценарий:
- Ожидаемое и фактическое состояние `champion`:
- Инженерное решение и рассмотренная альтернатива:
- Риск и способ обнаружения:
- Команда воспроизведения:
- Использование ИИ и выполненная самостоятельная проверка:

На защите участник показывает артефакт в tag `lr10-v1`, разрешает alias в exact version,
выполняет назначенный сценарий и объясняет, почему история Registry не удаляется.
