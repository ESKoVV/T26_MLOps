# Evidence card ЛР12

| Поле | Что указать |
|---|---|
| Студент | ФИО, группа, команда, GitHub-логин |
| Командная версия | tag `lr12-v1`, commit SHA и model version |
| Роль | зона ответственности и отличие от ЛР11 |
| Issue и PR | ссылки, критерии приёмки и review другого участника |
| Личный артефакт | окно, metric, policy, тест, отчёт, runbook или postmortem |
| Индивидуальный запуск | команда, параметры, `as_of` и путь к личному JSON-отчёту |
| Решение | `hold`, `investigate`, `incident_review`, `retraining_review` или `no_action` |
| Риск | leakage, незрелые labels, низкий coverage, малое окно или ложный drift |
| Использование ИИ | инструмент и самостоятельно проверенные утверждения |

Совпадающие карточки не принимаются. Количество commit без содержательного артефакта не
подтверждает вклад.
