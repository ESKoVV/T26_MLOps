# Политика безопасности учебного проекта

Не публикуйте секреты, персональные или закрытые данные в issue, pull request и логах. Сообщите преподавателю и владельцу команды через закрытый согласованный канал: commit/run, тип риска, время обнаружения и уже выполненные безопасные действия. Не копируйте само значение секрета.

Если секрет попал в Git, считать его скомпрометированным: сначала отозвать или ротировать, затем исправить источник и проверить историю/артефакты. Простое удаление из последнего commit недостаточно.

Учебный репозиторий не принимает реальные уязвимые данные. Любой security gate может остановить release до review владельца.
