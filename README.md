# MLOps 2026–2027

Комплект актуализируется по РПД для направления 09.03.02, профиль «Машинное обучение и искусственный интеллект», очная форма, 7 семестр. Курс рассчитан на 16 недель: 16 лекций и 16 лабораторных работ по 2 академических часа; ЛР16 включает защиту сквозного проекта.

Организация потока: не менее 30 студентов, команды по 2–5 человек, обязательная индивидуальная evidence card и индивидуальная защита каждой ЛР.

## Сдача работ через GitHub и СКИФ

Ветку команды (`team-XX`) ведет преподаватель. Тимлид делает fork репозитория курса; в нем `main` является интеграционной веткой команды, а для каждого участника создается отдельная ветка. Участник делает fork назначенной ветки тимлида, работает в своем `main` и открывает личный PR в эту ветку тимлида. Тимлид одобряет личные PR, интегрирует их в свой `main` и отвечает за итоговую ссылку в СКИФ.

- ЛР1: тимлид открывает PR `teamlead-fork:main` → `teacher-repository:team-XX`; в СКИФ прикладывается ссылка на этот PR.
- ЛР2–ЛР15: в СКИФ прикладывается ссылка на актуальный `main` fork-а тимлида после интеграции личных PR.
- ЛР16: тимлид снова открывает PR `teamlead-fork:main` → `teacher-repository:team-XX`; в СКИФ прикладывается ссылка на этот PR.

Схема хранится в файле `схема сдачи работ.jpg`. Все личные PR должны быть одобрены; прямые commits в ветки преподавателя не принимаются.

## Контрольные материалы

- `Проверка изменений РПД 2026-2027.md` — аудит новой редакции РПД и перечень решений до утверждения.
- `Сопоставление с курсом СКИФ 2026-2027.md` — контрольная карта 16 недель, артефактов и индивидуальной сдачи.
- `Технологический стек MLOps 2026-2027.md` — редактируемое описание GitHub и других технологий курса.
- `Журнал MLOps 2026-2027.xlsx` — журнал потока; требует синхронизации с 16 ЛР.
- `starter-project/` — сквозной проект прогноза задержки рейса.
- `Учебные издания/Учебное пособие/` — сводное учебное пособие по 16 лекциям с демонстрационными
  и отказными сценариями в Markdown, DOCX и PDF.
- `Учебные издания/Лабораторный практикум/` — отдельный практикум по ЛР1–ЛР16 с правилами
  командной и индивидуальной сдачи в Markdown, DOCX и PDF.
